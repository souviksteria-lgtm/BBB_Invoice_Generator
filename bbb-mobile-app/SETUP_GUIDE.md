# Mobile App Setup Guide

## Quick Start

### Step 1: Copy Web Files

Copy these files from the parent directory to `www/`:

```bash
# From the root BBB_Invoice_Generator directory:
cp index.html bbb-mobile-app/www/invoice.html
cp myorder.html bbb-mobile-app/www/
cp catalogue.json bbb-mobile-app/www/
cp signature.png bbb-mobile-app/www/
```

Or manually copy them using your file explorer.

### Step 2: Create Mobile Landing Page

The `www/index.html` (already created) should link to both invoice and order pages:

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="initial-scale=1, width=device-width, viewport-fit=cover">
  <title>BBB Invoice Generator</title>
  <style>
    body {
      font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Arial, sans-serif;
      background: #f0f4f8;
      margin: 0;
      padding: 20px;
    }
    .container {
      max-width: 500px;
      margin: 0 auto;
      text-align: center;
    }
    h1 {
      color: #7b1a1a;
      margin-bottom: 30px;
    }
    .btn {
      display: block;
      padding: 15px 20px;
      margin: 10px 0;
      background: #3182ce;
      color: white;
      text-decoration: none;
      border-radius: 8px;
      font-size: 16px;
      font-weight: 600;
    }
    .btn:hover {
      background: #2b6cb0;
    }
  </style>
</head>
<body>
  <div class="container">
    <h1>Beyond Blissful Bakes</h1>
    <p>Select an option:</p>
    <a href="invoice.html" class="btn">📋 Generate Invoice</a>
    <a href="myorder.html" class="btn">🛒 Generate Order</a>
  </div>
</body>
</html>
```

### Step 3: Install Dependencies

```bash
cd bbb-mobile-app
npm install
```

### Step 4: Add Android Platform

```bash
cordova platform add android
```

### Step 5: Build and Run

**Debug Build:**
```bash
cordova build android
```

**Run on Device:**
```bash
cordova run android
```

## File Organization

After copying files, your `www/` directory should look like:

```
www/
├── index.html            # Landing page with navigation
├── invoice.html          # Invoice generator
├── myorder.html          # Order generator  
├── catalogue.json        # Product data
├── signature.png         # Store logo
└── cordova.js           # (Auto-generated by Cordova)
```
